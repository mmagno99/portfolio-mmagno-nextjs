Um **desenvolvedor back-end** garante que tudo o que acontece por trás da interface gráfica funcione corretamente.

Seu trabalho abrange desde a gestão de bancos de dados, servidores e APIs até a segurança da aplicação.

- **Node.js:** Para construir servidores rápidos e escaláveis com JavaScript.
- **Python:** Com frameworks como Django ou Flask para APIs robustas.
- **Java:** Muito utilizado em aplicações empresariais com Spring Boot.
- **Ruby on Rails:** Ideal para startups que buscam agilidade.
- **Bancos de dados:** MySQL, PostgreSQL e MongoDB são essenciais no seu conjunto de ferramentas.

Veja um exemplo básico de um servidor em Node.js:

```javascript
const express = require('express');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
  res.send('Olá do servidor!');
});

app.listen(PORT, () => {
  console.log(`Servidor rodando em http://localhost:${PORT}`);
});
```
