Um **desenvolvedor front-end** constrói toda a parte visual e interativa de um site ou aplicação.

Utiliza tecnologias essenciais como **HTML, CSS e JavaScript** para transformar um design em algo funcional e agradável para o usuário.

Além dessas tecnologias, costuma trabalhar com frameworks modernos como **React, Vue ou Angular** para construir interfaces dinâmicas e eficientes.

Veja uma estrutura básica que todo desenvolvedor front-end deve dominar:

```html
<!DOCTYPE html>
<html lang="pt">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Minha primeira página</title>
    <style>
      body {
        font-family: 'Poppins', sans-serif;
        background-color: #f4f4f4;
        color: #333;
        text-align: center;
        padding: 50px;
      }
    </style>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Esta é minha primeira página web.</p>
  </body>
</html>
```

Um desenvolvedor front-end não deve apenas escrever código: também precisa garantir que seu trabalho seja acessível, rápido, otimizado para SEO e adaptável a todos os dispositivos.
