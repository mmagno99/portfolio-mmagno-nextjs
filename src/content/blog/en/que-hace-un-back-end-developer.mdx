A **back-end developer** makes sure that everything behind the graphical interface works correctly.

Their work ranges from managing databases, servers and APIs to application security.

- **Node.js:** For building fast, scalable servers with JavaScript.
- **Python:** Using frameworks such as Django or Flask for robust APIs.
- **Java:** Widely used in enterprise applications through Spring Boot.
- **Ruby on Rails:** Ideal for startups looking for agility.
- **Databases:** MySQL, PostgreSQL and MongoDB are essential parts of their toolkit.

Here is a basic example of a Node.js server:

```javascript
const express = require('express');
const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
  res.send('Hello from the server!');
});

app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});
```
