A **front-end developer** builds the visual and interactive parts of a website or application.

They use essential technologies such as **HTML, CSS and JavaScript** to turn a design into something functional and pleasant to use.

Alongside these technologies, they often work with modern frameworks such as **React, Vue or Angular** to build dynamic, efficient interfaces.

Here is a basic structure that every front-end developer should master:

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>My first page</title>
    <style>
      body {
        font-family: 'Poppins', sans-serif;
        background-color: #f4f4f4;
        color: #333;
        text-align: center;
        padding: 50px;
      }
    </style>
  </head>
  <body>
    <h1>Hello World!</h1>
    <p>This is my first web page.</p>
  </body>
</html>
```

A front-end developer does more than write code: they also need to make their work accessible, fast, optimized for SEO and adaptable to every device.
